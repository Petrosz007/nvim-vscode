# nvim-vscode

```sh
git clone git@github.com:Petrosz007/nvim-vscode.git ~/.config/nvim-vscode
```

Neovim configuration to be used inside VS Code

- https://github.com/vscode-neovim/vscode-neovim
- https://github.com/VSpaceCode/vscode-which-key

You need to run nvim once to install the plugins with lazy.nvim (I guess, I don't think a headless nvim would trigger lazy.nvim's installation)

```sh
NVIM_APPNAME=nvim-vscode nvim init.lua
```
